# TypeScript E-commerce App

A simple e-commerce web application built using **HTML, CSS, Bootstrap, TypeScript, and LocalStorage**. This project demonstrates product management, user authentication, shopping cart functionality, and checkout flow without requiring a backend server.

## Features

- **User Authentication:** Registration and login functionality.
- **Admin Panel:** Manage product categories and products.
- **Product Management:** Add, edit, and delete products.
- **Product Listing:** Display product details, images, categories, and prices.
- **Shopping Cart:** Add products and increase or decrease quantities.
- **Cart Summary:** Calculate subtotal, 18% GST, and grand total.
- **Checkout:** Confirm orders using a Bootstrap modal.
- **LocalStorage:** Store users, products, categories, and cart data in the browser.
- **Responsive UI:** Built with Bootstrap 5.

## Tech Stack

- HTML
- CSS
- Bootstrap
- Bootstrap Icons
- TypeScript
- Browser LocalStorage

## Prerequisites

Before starting, make sure you have installed:

- [Node.js and npm](https://nodejs.org/)
- [Visual Studio Code](https://code.visualstudio.com/)
- The Live Server extension in VS Code

## Getting Started

### 1. Clone the repository OR Download it

Open a terminal and run:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Navigate to the project directory:

```bash
cd Typescript-EcommerceApp
```

Replace the repository URL with the URL from the GitHub **Code** button.

### 2. Install dependencies

```bash
npm install
```

This installs the project dependencies listed in `package.json`.

### 3. Compile TypeScript

Run the following command to compile TypeScript files into JavaScript:

```bash
npx tsc
```

The generated JavaScript files will be placed in the `dist/` directory according to `tsconfig.json`.

### 4. Start TypeScript watch mode

For automatic recompilation whenever you modify TypeScript files, run:

```bash
npx tsc --watch
```

Keep this terminal running while developing.

### 5. Run the application

1. Open the project folder in Visual Studio Code.
2. Start the Live Server extension from the project.
3. Open `pages/register.html` in the browser through Live Server.
4. Register a user and explore the application's functionality.

**Important:** Compile the TypeScript before launching the application. If you change TypeScript files while watch mode is running, the compiler will rebuild the JavaScript automatically.

## Data Storage

This project uses browser LocalStorage instead of a backend database.

- Application data is stored in the current browser's LocalStorage.
- Data is specific to the browser and origin being used.
- Clearing browser storage may delete the saved application data.
- Data is not automatically shared across different browsers or devices.
